# 📊 Data Cleaning & Reporting Automation

An automated Python-based application that cleans, validates, analyzes, visualizes, and generates reports from CSV and Excel datasets.

## 🚀 Features

* 📂 CSV & Excel file upload
* 🧹 Automatic data cleaning
* ✅ Data validation
* 📊 KPI & statistical analysis
* 📈 Automatic visualizations
* 💡 Data insights
* 📑 Automated Excel reports
* 🎨 Interactive Streamlit dashboard

## 🛠️ Technologies

**Python • Pandas • NumPy • Matplotlib • Seaborn • OpenPyXL • Streamlit**

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
